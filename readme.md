
# GapMap — Personalized Learning Gap Detection

GapMap is a student-focused learning platform that helps learners identify
concepts they need to improve, review targeted explanations, and practise
questions to strengthen their understanding.

## Problem

Students may struggle with foundational concepts without knowing exactly
which topic they need to revise. Teachers also need a simple way to understand
which concepts require additional attention.

## Solution

GapMap provides a simple learning journey:

1. Complete a diagnostic assessment.
2. Review the results and identify concepts that need attention.
3. Read a focused lesson with examples.
4. Practise questions and check understanding.
5. Review sample teacher insights.

## Features

- Student-friendly dashboard
- Diagnostic question flow
- Concept-level learning recommendations
- Focused lessons and practice questions
- English, Telugu and Hindi language options
- Sample teacher insights and mastery visualization
- Responsive website layout
- No paid API key required for the demo

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Start the assessment and test the learning flow.

## Deployment

This project can be hosted using GitHub Pages because its frontend uses
static HTML, CSS and JavaScript.

1. Upload the project files to a GitHub repository.
2. Open the repository's Settings.
3. Select Pages.
4. Select the deployment source and the `main` branch.
5. Select the root folder (`/`).
6. Save and wait for GitHub Pages to publish the website.

## Important Demo Note

Teacher insights and sample mastery figures are illustrative demo data.
They are not real student records or validated educational research results.

The current prototype uses predefined diagnostic logic. It should not be
described as a scientifically validated AI assessment unless that capability
has been implemented and evaluated.
